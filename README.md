# こいみくじ｜日本×韓国 恋愛相性診断

生年月日と文化圏をもとに、星座・数秘・恋愛コミュニケーションの傾向からふたりの相性を読み解く、スマートフォン対応のサンプルサイトです。占いは娯楽・自己理解のためのヒントです。

## GitHubに公開する

このフォルダーの中身を新しいGitHubリポジトリにアップロードします（ZIPファイル自体ではなく、展開したファイル一式）。`.env` やAPIキーをコミットしないでください。`.gitignore` で `.env` は除外されます。

GitHubへアップロードする前に、リポジトリのファイル一覧に `.env` が含まれていないことを確認してください。誤ってキーを公開した場合は、そのキーをただちに無効化し、新しいキーを発行してください。リポジトリにライセンスを追加していない場合、他の人に利用・再配布を許諾したことにはなりません。

## 起動方法

1. Node.js 18以降をインストール
2. このフォルダーで `npm install`
3. `.env.example` を `.env` にコピー（PowerShell: `Copy-Item .env.example .env` / macOS・Linux: `cp .env.example .env`）
4. `.env` の `OPENAI_API_KEY=` の右側1か所にご自身のAPIキーを入力
5. `npm start` を実行
6. ブラウザーで `http://localhost:3000` を開く

APIキーはExpressサーバーだけが読み込みます。ブラウザーへ返すコードや画面には含めません。`.env` はGit管理対象外です。AI個別鑑定を利用しない場合も基本診断は動作しますが、追加3問への回答から個別鑑定を生成するには有効なAPIキーが必要です。OpenAI APIの利用料はアカウント設定に従います。

## 含まれる診断

- 太陽星座の特性と相性スコア
- 生年月日から算出するライフパス数
- 日本・韓国の文化圏を考慮した会話や愛情表現の見立て
- 恋愛、会話、ときめき、信頼、将来性の5項目
- 相手から見たあなた、すれ違いやすい点、関係を育てるヒント
- 3つの追加質問と、サーバー経由のAI個別鑑定

## 注意

文化圏による説明は一般化を避けるための参考視点であり、個人差が大きいものです。AI個別鑑定を依頼すると、追加質問への回答と診断要約がOpenAI APIへ送信されます。氏名や連絡先など、不要な個人情報を入力しないでください。

このリポジトリはローカル実行を想定したサンプルです。インターネットへサービスとして公開する前に、プライバシーポリシー、利用規約、HTTPS、レート制限、不正利用対策、ログや入力データの取り扱いを整備してください。
